## 必要驗收情境

- 教師和學生使用不同 browser context，能登入、開課、換頁、作答、揭露結果。
- 未開放／已結束活動拒絕提交；重送 `submissionId` 不重複保存。
- 學生不能呼叫教師 API、讀取其他班／學生答案，或提早取得正解與教師備註。
- 課程修改後，已開課場次仍顯示原始教材快照。
- 重新整理／重啟後能讀回應保存的資料；失敗時不冒充「已儲存」。
- 搶答在並行提交下仍只選一位贏家。
- 白板在切頁、儲存及重開後能還原；資料只屬於對應頁面。
- 自訂 HTML 只能透過受控 bridge 提交，不接受其他 window 的偽造訊息。
- AI mock／失敗不阻擋作答；敏感題與未允許的回答不送外部 AI。
- 匯出課程不帶作答，備份不帶登入憑證，還原不能接管別人的資料。

## v0.1 範圍

目前提供課程 JSON 編輯與固定視覺化、自訂 HTML 沙箱，以及基本課堂互動。沒有自由拖曳投影片編輯器、媒體上傳管理、真正匿名敏感問卷、多人共同備課或可保證的離線完整授課。雷射／聚光是顯示端輔助；不把學生網路時間用於公平的毫秒級競賽。

正式資料為小型部署用 snapshot，並非已完成跨校多租戶設計。本機測試通過後仍需部署者完成雲端權限、iPad／大螢幕及班級網路測試。
