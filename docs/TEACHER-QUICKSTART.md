# 老師的一頁使用指南

## 上課前

1. 在教室觸控大螢幕開啟網站，選擇「我是教師」。本機按「教師示範」；正式網站用自己的教師帳號登入。
2. 匯入或選擇課程，查看各頁內容與活動答案。第一次先用假資料試教。
3. 選擇班級並開始課堂。正式班級的學生識別碼分別交給學生；不要把全班識別碼投影。
4. 在班級頁開啟學生入口 QR Code，讓學生 iPad 掃描，以班級、座號、識別碼登入。若是 `127.0.0.1` 本機示範網址，其他裝置無法連入；跨裝置請先完成正式部署。
5. 設定你要跟隨教師換頁或讓學生自主閱讀，再確認教室 Wi-Fi 能連線。教師開啟「大屏授課」可使用大工具列。

## 上課中

| 想做的事 | 操作重點 |
| --- | --- |
| 帶全班看簡報 | 教師換頁；學生跟隨模式會同步 |
| 請學生回答 | 開放該頁活動；學生看到已儲存才算完成 |
| 看班級想法 | 關題後選擇公布結果；投影只顯示你準備公開的內容 |
| 在畫面註記 | 開啟畫筆，以手指或觸控筆書寫；不寫時切回操作工具 |
| 指出重點 | 雷射筆／聚光燈配合教師顯示畫面使用 |
| 抽學生分享 | 抽籤；避免把尚未準備的私密回答直接投影 |
| 全班搶答 | 教師開放搶答，學生按下；後端以接受順序判定 |
| 看 AI 摘要 | 教師發起並先審閱；模擬結果會標示，不能當真實模型分析 |

大螢幕介面設計以觸控為主，重要操作至少 48px，教學工具使用更大的觸控區。瀏覽器全螢幕與投影模式依裝置支援程度不同；無法進全螢幕仍可正常上課。

## 下課後

1. 結束場次，下載作答 JSON／CSV；如需分享教材，下載的是課程 JSON。
2. 確認保存與匯出結果。資料留多久由學校／老師決定，定期清理不需要的場次。
3. 公用大螢幕登出教師帳號。學生 iPad 若為共用設備，也應登出。

學生忘記識別碼時，老師可在「班級與學生」指定座號重發，記下新識別碼後個別交付；舊識別碼與舊登入隨即失效。

學生切到別的 App 或鎖定 iPad 後再回來，先等畫面更新並查看送出狀態。若網路中斷，請先確認是否已儲存，不要把按過按鈕當成成功繳交。
